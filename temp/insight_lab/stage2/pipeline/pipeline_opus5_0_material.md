# [opus5] MATERIAL v2 — The Rigged Prime Race  ·  **puzzle**

_Why this form:_ The insight can be posed as a concrete race with an objectively checkable answer (which lane leads, and by how much), and the correct answer is counterintuitive yet derivable in the head once you notice where prime squares land. The mechanism is the payoff, not a matter of interpretation.

## Prerequisites (footing, defined in-document)
- **Odd primes mod 4** — Every odd number leaves remainder 1 or 3 when divided by 4, so apart from the prime 2 every prime falls into exactly one of two lanes: 1 mod 4 (5, 13, 17, 29, ...) or 3 mod 4 (3, 7, 11, 19, 23, ...).
- **π(x) and the Prime Number Theorem** — π(x) is the count of primes up to x; PNT says π(x) ~ x/log x, i.e. the ratio tends to 1. The refined form says π(x) is even better approximated by the logarithmic integral Li(x).
- **Counting function in an arithmetic progression, π(x; 4, a)** — π(x; 4, a) is the number of primes p ≤ x with p ≡ a (mod 4). The 'race' is the running difference D(x) = π(x; 4, 3) − π(x; 4, 1).
- **Dirichlet's theorem / equidistribution in progressions** — Dirichlet (1837) proved each admissible residue class mod q contains infinitely many primes, and the refined version says the primes split asymptotically evenly among the φ(q) admissible classes. For q = 4 that means π(x; 4, 1)/π(x) → 1/2 and π(x; 4, 3)/π(x) → 1/2.
- **Asymptotic density says nothing about the difference** — Two counts can each be ~x/(2 log x) while their difference is as large as x^{1/2}/log x or bigger, because that difference is still o(x/log x). Equal density constrains only the leading term; the race is decided entirely by lower-order terms.
- **Prime powers and Chebyshev's weighted count ψ** — ψ(x) = Σ_{p^k ≤ x} log p sums over all prime powers, giving each power p^k the weight log p (the von Mangoldt weight). It is the natural analytic scoreboard because ψ(x) ~ x exactly, with no messy log; note p^k gets weight log p = (1/k)·log(p^k), so a square counts 'half' as much as a prime of its own size.
- **Odd squares are 1 mod 4** — If n is odd, n = 2m+1, then n² = 4m(m+1)+1 ≡ 1 (mod 4) (in fact ≡ 1 mod 8). So the square of every odd prime lies in the class 1 mod 4 — never in 3 mod 4.
- **Dirichlet L-functions, the explicit formula, and GRH** — To each residue class mod q one attaches characters χ and L-functions L(s, χ); an 'explicit formula' expresses prime counts as a main term plus a sum over the zeros ρ of these L-functions of terms x^ρ/ρ. The Generalized Riemann Hypothesis says all such zeros have real part 1/2, which makes every one of those oscillating terms of size exactly x^{1/2}, and their sum has average value zero.
- **Logarithmic density** — The logarithmic density of a set S of real x ≥ 2 is lim (1/log X) ∫_{S ∩ [2,X]} dt/t — a weighting that gives each 'decade' of x equal say. It is used because for prime races the ordinary density of {x : D(x) > 0} is not known to exist, while the logarithmic density provably does under GRH.
- **Sign change** — A value of x at which the running difference D(x) switches sign — i.e. where the trailing lane pulls level and then ahead.

**The turn:** Lane 3 leads not because primes prefer it, but because every prime square is 1 mod 4, so the only unbiased scoreboard secretly hands lane 1 a phantom √x head start that the primes must be paying back.

End on the reframing: this is a fact about squares, not about primes.
