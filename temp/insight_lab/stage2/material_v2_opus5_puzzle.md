# [opus5] MATERIAL v2 — Equally Common, Unequally Awaited  ·  **puzzle**

_Why this form:_ The insight can be posed as a concrete numerical question — how long until HH versus HT? — whose objective answers (6 and 4) are head-derivable yet counterintuitive; the mechanism behind the difference is the real payoff.

## Prerequisites (footing, defined in-document)
- **Fair coin flip / independent Bernoulli trials** — Each flip is H or T with probability 1/2 each, independent of every other flip. Nothing about past flips changes the distribution of the next one.
- **Expected value (expectation)** — The probability-weighted average of a random quantity: E[X] = Σ x·P(X = x). It is linear: E[X+Y] = E[X] + E[Y] always, even when X and Y are dependent.
- **Conditional expectation / law of total expectation** — You may split on the outcome of one step: E[X] = Σ_i P(case i)·E[X | case i]. This is the engine that turns a waiting-time problem into a system of linear equations.
- **First-passage time** — The number of steps a process takes to reach a target state for the first time, starting from a given state. Here: number of flips until the target 2-letter pattern first appears as consecutive flips.
- **State (as a summary of history)** — A compressed description of the past that is sufficient to predict the future. For 2-letter patterns, all you need to remember is how much of the pattern you currently have matched — typically just the last flip.
- **Geometric waiting time** — If an event has probability p on each independent trial, the expected number of trials until its first occurrence is 1/p. So the expected wait for the first H is 2.
- **Indicator variables and linearity** — An indicator I_A equals 1 if event A happens and 0 otherwise, so E[I_A] = P(A). Summing indicators and using linearity counts expected occurrences without worrying about dependence between the terms.
- **Inter-arrival gap / renewal spacing** — If a pattern occurs at positions t₁ < t₂ < …, the gaps are t₂−t₁, t₃−t₂, … . If a pattern occurs on average once every 4 flips, the long-run average gap is 4.
- **Length-biased sampling (the inspection paradox)** — If you land at a uniformly random point in time among intervals of varying lengths, you are more likely to land inside a long interval than a short one — proportionally to its length — so the interval you observe is longer on average than a randomly chosen interval.
- **Second moment and variance** — E[G²] measures spread as well as center: E[G²] = Var(G) + (E[G])². Two distributions can share a mean while one has a much larger second moment because its values are more spread out.
- **String self-overlap (autocorrelation)** — A string overlaps itself at length k if its first k characters equal its last k characters. 'HH' has a length-1 overlap (H = H); 'HT' has none (H ≠ T). This is exactly the quantity a KMP failure function tabulates.
